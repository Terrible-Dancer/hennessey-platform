Live Setup

Connect the secure Hennessey application services

1 · Run as an application

V4.2.1 includes a Node server. Live AI cannot run when the HTML file is opened directly.

Local test:
npm install
npm start
Then open http://localhost:3001.

Deployment

Deploy this folder to a Node-compatible host. Add environment variables in the host's secure settings rather than editing the HTML.

2 · Secure credentials

OPENAI_API_KEY
Enables live AI brief interpretation.

OPENAI_MODEL
Configured server-side for live AI interpretation.

External Provider Layer
Provider-independent architecture. People Data Labs is the first implemented adapter; Coresignal and Crustdata are reserved adapters for comparative testing.

PDL_API_KEY
Enables the current PDL adapter. Provider credentials remain server-side.

Never place API keys in browser code or send them in chat.
